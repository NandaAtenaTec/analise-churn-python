# 📊 Análise de Churn de Clientes

## 🎯 Sobre o projeto

Este projeto apresenta uma análise exploratória de dados de clientes de uma instituição financeira, com o objetivo de identificar padrões relacionados ao cancelamento de cartões.

A análise foi desenvolvida utilizando Python, Pandas e Plotly, explorando características dos clientes e comparando diferentes perfis entre clientes ativos e clientes que cancelaram seus cartões.

## 🎯 Objetivo

Investigar os principais padrões presentes nos dados e identificar características que podem estar relacionadas ao cancelamento de clientes.

A análise busca responder perguntas como:

- Qual é a proporção de clientes ativos e cancelados?
- Quais características aparecem com maior frequência entre os clientes que cancelaram?
- Existem padrões de comportamento associados ao churn?
- Quais informações podem ajudar a empresa a entender melhor seus clientes?

## 🛠️ Tecnologias utilizadas

- 🐍 Python
- 🐼 Pandas
- 📊 Plotly
- 🔎 Análise Exploratória de Dados
- 📈 Visualização de Dados
- ☁️ Google Colab

## 🔎 Etapas da análise

1. Importação dos dados
2. Exploração inicial da base
3. Verificação e tratamento dos dados
4. Análise das variáveis
5. Comparação entre clientes ativos e cancelados
6. Visualização dos dados
7. Identificação de padrões e insights

## 📈 Principais análises

Foram utilizadas visualizações para comparar as características dos clientes de acordo com sua situação, permitindo observar possíveis diferenças entre clientes ativos e clientes que cancelaram.

## 💡 Insights

Os resultados da análise são apresentados no notebook, com gráficos e comparações das principais características dos clientes.
